# Rover Software for Teams

## Rover code (copy one file into the SPIKE App)
- `spike_basics.py` - Basic Functions package
- `spike_wall_follower.py` - Wall Follower package
- `spike_explorer.py` - Maze Explorer package
- `spike_all_in_one.py` - everything together (the simulator runs this by default)

## Simulator
Run `python sim/serve_sim.py` and it opens in your browser. Use "File to run" to pick your own package.

## Documents (in `docs/`)
- User manuals for each package and for the simulator
- Organiser Guide and Presentation Script
- `presentation/` - the team presentation slides
