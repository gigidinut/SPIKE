The simulator

Free for every team. Runs your real program on a computer, with your rover and your course.

Every package has the basic functions. The two autonomy packages each add one brain on top.

The software is built like LEGO. At the bottom are the basic functions: driving, turning, the distance sensor, the colour sensor, and a set of tests called setup_check. Every package has these. On top you can add one brain: the wall follower, or the maze explorer. And next to all of it is the simulator, which every team gets for free, whichever package you buy. It runs your real program on a computer, with a pretend version of your rover on a pretend version of the course.
