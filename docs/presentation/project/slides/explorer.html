It maps the course and searches all of it

  1. Plan: pick the nearest square not searched yet.
  2. Look: measure ahead; one look maps a whole line.
  3. Move one square, and repeat until done.

await explore(find=color.GREEN,

Good for

Patches anywhere it can reach. Colours in a set order.

Watch out

Could be slower. Hints help.

Orange squares: floor it has searched. It reaches both patches, but it visits every square to get there.

Package three: the maze explorer. The rover thinks of the floor as a grid of small squares, and draws a map as it goes. Over and over, it plans: which is the nearest square I haven’t searched yet? It looks: one measurement with the distance sensor maps a whole line of squares. And it moves one square. It keeps going until it has searched everywhere it can reach. So it finds patches anywhere, even in the middle of the floor. It can also find colours in a set order: explore with find equals GREEN stops on green, does your actions, and then you can explore for the next colour. The cost is time: a full search takes minutes. You can give it hints, like near equals minus 30, 110, meaning roughly 30 centimetres left and 110 ahead, so it searches there first.
