Here’s your first hour, and it’s in the manual too. One: copy your file into a new Python project in the SPIKE App. Two: fill in the settings for your rover: ports, wheel size, where the sensors are. Three: draw your rover in the simulator; it tells you if your settings don’t match. Four: run setup_check on the real rover, and fix whatever it reports. Five: run your program in the simulator. Six: only then, run it on the floor. One tip that will save you a lot of trouble: keep one master copy of your program file. Change it, test it in the simulator, then copy it into the SPIKE App. If you change it in the SPIKE App, copy it straight back, or you’ll end up with two versions.
