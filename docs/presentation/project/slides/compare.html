Here they are side by side. With Basic functions you plan the route; with the other two, the rover does. Basic functions finds a patch only if your route goes over it. The wall follower finds patches along the walls, but it misses patches out in the open floor. The explorer finds patches anywhere it can reach. If the colours must be found in a set order, Basic functions can do that because you write the route, and the explorer can do it with explore(find=…); the wall follower simply reacts to colours in the order it meets them. And the price of that: a hard-coded route is fastest, the wall follower is in the middle, and a full search with the explorer takes minutes. Prices: [read out prices].
